### Sobre mim

Desenvolvedora Full Stack no **Grupo Mônaco**, onde construo e evoluo sistemas corporativos aplicando **Domain-Driven Design** e arquitetura em camadas para lidar com domínios de negócio complexos.

Trabalho na ponta a ponta do produto: modelagem de domínio, APIs em Laravel, integração com bancos Oracle de missão crítica e interfaces em Angular — sempre buscando código limpo, manutenível e escalável.

- 🔭 Atualmente construindo módulos corporativos com **Laravel + Angular + Oracle**, seguindo padrões de **DDD**
- 🧠 Explorando **Java/Spring Boot** para ampliar repertório em backend
- 🎓 Cursando **Ciência da Computação**, unindo teoria e prática do dia a dia profissional
- 🤝 Gosto de resolver problemas de arquitetura e performance de banco de dados

<br>
